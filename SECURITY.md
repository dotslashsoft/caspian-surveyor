## Reporting a Vulnerability

If you discover a potential security vulnerability in Caspian Surveyor, please report it privately using GitHub's **Report a vulnerability** feature rather than opening a public issue.

Please include, when applicable:
- The affected Caspian Surveyor version
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Relevant logs, screenshots, or other supporting information
- Any suggested mitigation or fix, if known

Please avoid including personal or sensitive information in a vulnerability report unless it is necessary to reproduce the issue.

Security reports will be reviewed as soon as reasonably possible. Caspian Surveyor is maintained as a hobby project, so no specific response or resolution timeframe can be guaranteed.

If a reported vulnerability is confirmed, I will work to address it and coordinate disclosure as appropriate.

For ordinary bugs, crashes, or feature requests that do not involve a security concern, please use the repository's public GitHub Issues.
