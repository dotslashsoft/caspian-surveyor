# Caspian Surveyor - Keyboard Shortcuts/Hotkeys

---

Annotated Positions:
- [0, 0] - default panel
- [1, 0] - from default panel, cycle right once
- [1, 1] - from default panel, cycle right once, cycle down once
- [1, 2] - from default panel, cycle right once, cycle down twice

---

## Keyboard Shortcuts/Hotkeys

- `Ctrl + Shift + M` - Toggle HUD visibility.
- `Ctrl + Shift + E` - Exit Caspian Surveyor.
- `Ctrl + Shift + R` - Toggle REBOUND panel.
- `Ctrl + Shift + U` - Open Caspian Surveyor's GitHub Releases
- `Ctrl + Alt + Right` - Navigate to the next celestial body.
  - [1, 0] -> [2, 0] -> [3, 0]
  - Body 1 -> Body 2 -> Body 3
- `Ctrl + Alt + Left` - Navigate to the previous celestial body.
  - [3, 0] -> [2, 0] -> [1, 0]
  - Body 3 -> Body 2 -> Body 1
- `Ctrl + Alt + Down` / `Ctrl + Alt + Up` - Cycle between information panels for the selected celestial body.
  - [1, 0] -> [1, 1] -> [1, 2]
  - Celestial Body -> Exobiology -> Physical/Orbital
- `Ctrl + Alt + ]` - Toggle the planetary orbital and physical data legend.
- `Ctrl + Alt + Home` - Return to the default panel.

---

## Navigating Caspian Surveyor Panels
When launching Caspian Surveyor, the default panel will always show, which is the system summary panel.

Once `Ctrl + Alt + Left` or `Ctrl + Alt + Right` has been pressed, the only way to get back to the system summary panel is by using the `Ctrl + Alt + Home`. Once you leave the default system summary panel, horizontal navigation (x-axis) cycles between celestial bodies within the current system. Vertical navigation (y-axis) cycles between the Celestial Body, Exobiology, and Physical/Orbital panels for the currently selected body.
